Project Overview
This project demonstrates my ability to use SQL to retrieve, filter, organize, and analyze data stored in relational databases. I used SQL queries to investigate datasets, answer questions, and extract meaningful information to support data-driven decision-making.

Objectives
* Retrieve relevant data from database tables.
* Filter and sort records based on specific conditions.
* Summarize data using aggregate functions.
* Explore relationships between tables.
* Use SQL queries to answer analytical questions.

Tools Used
* MySQL Workbench

SQL Skills Demonstrated
* SELECT — retrieving data from tables.
* WHERE — filtering records based on conditions.
* ORDER BY — sorting query results.
* Aggregate functions such as COUNT(), SUM(), and AVG().
* GROUP BY — summarizing data by categories.
* JOIN — combining related data from multiple tables, where applicable.

Project Process

1. Explored the database structure and identified relevant tables.
2. Reviewed the available columns and data.
3. Wrote SQL queries to retrieve and filter information.
4. Used appropriate functions to summarize and analyze records.
5. Interpreted query results to answer the project questions.
