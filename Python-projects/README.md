Customer Segmentation Using Unsupervised Learning

Project Type: Data Analytics / Machine Learning
Tools & Technologies: Python, Pandas, Scikit-learn, Matplotlib and Seaborn

Project Overview

This project focuses on applying unsupervised machine learning techniques to identify meaningful customer segments based on purchasing behaviour.

The objective is to uncover customer patterns, understand purchasing preferences, and generate insights that can support data-driven business decisions and targeted marketing strategies.

My Role and Responsibilities

As the Data Analyst working on this project, I:

* Imported and explored the dataset using Python.
* Performed data cleaning and preprocessing.
* Checked for missing values and duplicate records.
* Created customer-level features from transaction data.
* Applied customer segmentation techniques using unsupervised machine learning.
* Explored and visualised customer patterns to communicate findings.

Tools and Technical Skills

* Python: Data analysis and programming.
* Pandas: Data manipulation and preparation.
* Scikit-learn: Machine learning and clustering.
* Matplotlib & Seaborn: Data visualisation.

Project Objectives

* Identify distinct customer groups based on purchasing behaviour.
* Understand customer patterns and preferences.
* Support customer-focused marketing strategies.
* Demonstrate practical applications of Python and machine learning in data analytics.

Key Learning Outcomes

This project strengthened my practical understanding of Python programming, data preprocessing, exploratory data analysis, feature engineering and unsupervised machine learning.

It also enhanced my ability to transform raw data into meaningful insights that can support business decisions.
